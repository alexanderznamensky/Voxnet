# Вокснет для Home Assistant

Кастомная интеграция получает баланс из личного кабинета `https://voxnet.lantek.ru/` и создает для каждой учетной записи:

- отдельное устройство Вокснет;
- сенсор баланса в рублях;
- кнопку ручного обновления баланса;
- настройку интервала автоматического обновления через UI.

## Что добавлено в версии 1.1.1

Добавлена поддержка нескольких учетных записей.

Логика такая: **одна учетная запись = один экземпляр интеграции**.

Чтобы добавить вторую, третью и следующие учетные записи, нужно снова открыть:

**Настройки → Устройства и службы → Добавить интеграцию → Вокснет**

и ввести другой логин/пароль.

Для удобства добавлено поле **Название учетной записи**. Оно используется в названии устройства, например:

- `Вокснет Дом`
- `Вокснет Офис`
- `Вокснет Мама`

Один и тот же логин нельзя добавить дважды. Это сделано специально, чтобы Home Assistant не создавал дубли одной и той же учетной записи.

## Установка

1. Скопируйте папку `custom_components/voxnet` в папку Home Assistant:

```text
/config/custom_components/voxnet
```

2. Перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
4. Найдите **Вокснет**.
5. Введите логин, пароль, название учетной записи и интервал обновления в минутах.

Минимальный интервал — 60 минут. Рекомендуемый интервал — 60 минут.

## Добавление нескольких учетных записей

Для каждой учетной записи повторите добавление интеграции через UI.

Пример:

1. Добавили первую учетную запись с названием `Дом`.
2. Снова нажали **Добавить интеграцию**.
3. Добавили вторую учетную запись с названием `Офис`.
4. В Home Assistant появятся два отдельных устройства, два сенсора баланса и две кнопки ручного обновления.

## Изменение интервала

Откройте нужный экземпляр интеграции:

**Настройки → Устройства и службы → Вокснет → Настроить**

и измените `Интервал обновления, минут`.

Интервал задается отдельно для каждой учетной записи.

## Ручное обновление

После установки для каждой учетной записи появится своя кнопка **Обновить баланс**.

Нажатие кнопки запускает немедленный парсинг сайта только для соответствующей учетной записи.

## Важно

Интеграция использует HTML-селектор:

```text
tr:nth-child(5) > td:nth-child(2) > p
```

Если сайт изменит верстку, нужно будет изменить `SELECTOR` в файле `const.py`.
